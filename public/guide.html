The anatomy, mapped.

Every "product" feature of a coding agent wraps a small primitive. This lab lets you watch each one work — and watch one of them break.

The corruption the queues prevent

Run steered-fetch in immediate mode and inject while web_fetch is dispatching. Your user message lands between the assistant's tool-call message and the tool's observation — a transcript no real model API will accept, because every tool call must be answered by its result before any other role speaks. The badge flips to TRANSCRIPT CORRUPTED and the session log shows exactly where the splice happened.

Boundary mode is the fix used by real harnesses: buffer input on arrival, drain it only at model-request (steering) or would-stop (follow-up) boundaries. Same keystroke, safe landing.

Honest limits

  • The model is a playback deck. It cannot react to your steering content — it only shows where steered text lands in the message list. A real LLM would also change its behavior.
  • The shell is a command table. bash only runs commands the scenario registered, over an in-memory filesystem. Nothing touches your disk.
  • No context window, no retries, no approvals. Real harnesses add all three; they are deliberately out of scope here.
  • Single turn, single agent. No subagents, no headless mode, no remote executors.

This is an educational simulator, not agent infrastructure.
