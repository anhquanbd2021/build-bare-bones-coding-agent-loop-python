An agent is a while loop.

Watch one turn of a coding-agent loop: boundary → model → tool dispatch → observation → boundary — until the model returns text instead of a tool call. Inject steering mid-run and see where it lands.

Honest toy. The "model" is a deterministic playback deck — no LLM, no network, no real shell. The loop, the boundaries, the queues, and the session log are real.
